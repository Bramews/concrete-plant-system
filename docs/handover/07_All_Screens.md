# 7. جميع الشاشات (All Screens)

النظام مبني باستخدام مسارات Next.js (App Router). إليك تشريحاً دقيقاً ومملاً لجميع شاشات قسم المشغل (`/app/system/operator/`).

## 1. شاشة "قمرة القيادة" (Cockpit)
**المسار:** `/system/operator/cockpit/page.tsx`
- **هدفها:** الشاشة المركزية للمراقبة (Monitoring) وليست للتنفيذ. تترك مفتوحة طول اليوم.
- **من يدخلها:** المشغل أساساً، ويمكن لمدير المصنع فتحها للمراقبة.
- **المحتويات:**
  - **`MixerStatusBar.tsx`**: شريط عرضي ضخم يوضح حالة الخلاط الحالية (IDLE, WEIGHING, MIXING, DISCHARGING).
  - **`AlarmPanel.tsx`**: لوحة على اليمين أو اليسار تسرد الأخطاء (Faults). مثل "طرد زائد بالمحرك".
  - **`ProcessFlow.tsx`**: خريطة مبسطة كأنها أنبوب مضيء ينقل الكرات المضيئة من الصوامع للخلاط لتوضيح مسار الإنتاج.
  - **`LiveGauges.tsx`**: 4 دوائر قياس (Dial Gauges) بألوان متغيرة (أزرق للماء، رمادي للأسمنت، إلخ) تعرض الوزن اللحظي.

## 2. شاشة "الإنتاج" (Production)
**المسار:** `/system/operator/production/page.tsx`
- **هدفها:** العمل الحقيقي يتم هنا. اختيار الشاحنات وبدء الخلطات.
- **المحتويات:**
  - **حقل (Select Order):** قائمة منسدلة تسرد فقط الطلبات التي حالتها `LAB_APPROVED` أو `PRODUCTION`.
  - **حقل (Truck Number):** Text Input (إجباري).
  - **حقل (Driver Name):** Text Input (إجباري).
  - **حقل (Target Volume):** Number Input (إجباري، يجب أن يكون بين 1 والحد الأقصى للخلاط).
  - **`BatchForm.tsx`**: النموذج الذي يحوي الحقول أعلاه ويدير عملية التحقق (Validation) قبل التشغيل.
  - **بطاقة "ملخص ما قبل الإنتاج":** تظهر تلقائياً عندما تكتمل الحقول الأربعة، وتقول للمشغل: "ستقوم الآن بخلط 9 أمتار من نوع C35 للشاحنة T105".
  - **زر `إطلاق دفعة الخلط`:** الزر الأهم والأخطر. (مشروح في ملف الأزرار).
  - **جداول التذاكر (`TicketListClient.tsx`):** جدول أسفل الشاشة يعرض آخر التذاكر المصدرة اليوم، ليسهل طباعتها للسائق الواقف في الانتظار.

## 3. شاشة "المواد والصوامع" (Materials)
**المسار:** `/system/operator/materials/page.tsx`
- **هدفها:** مراقبة المخزون الفعلي المتبقي، والتخطيط لطلب مواد جديدة.
- **المحتويات:**
  - **رسومات الصوامع (`ScadaSiloSVG.tsx`):** رسمة SVG تفاعلية تشبه صومعة فيزيائية. السائل أو البودرة بداخلها ترتفع وتنخفض حسب المخزون `stock`.
  - **مؤشر الأيام المتبقية:** يحسب آلياً بناءً على المخزون (مثلاً: يكفي لـ 3 أيام).
  - **جرد الركام والماء:** خزانات (Bins) بحالات مماثلة.

## 4. شاشة "التذاكر والأرشيف" (Tickets)
**المسار:** `/system/operator/tickets/page.tsx`
- **هدفها:** البحث عن تذاكر قديمة للعملاء أو إعادة طباعة تذكرة ضاعت.
- **المحتويات:**
  - جدول بيانات (Data Table) يحتوي على (رقم التذكرة، التاريخ، الشاحنة، العميل، الكمية).
  - حقول بحث (Search) وتصفية (Filter).
  - زر طباعة لكل سطر.

## 5. شاشة "الإعدادات الصناعية" (Settings/ScadaConfig) - مخفية/للمدراء
**المسار:** `/system/operator/settings/page.tsx`
- **هدفها:** إعدادات الـ PLC و Modbus. خطيرة جداً ولا يدخلها المشغل العادي.
- **المحتويات:**
  - حقول لإدخال الـ IP Address الخاص بالـ PLC.
  - جداول لربط المتغيرات البرمجية بـ Registers حقيقية (Tag Mapping).
  - إعدادات התسامح (Tolerance) بالوزن، وأوقات الخلط الافتراضية (Default Mix Times).

## 6. الشاشات المشتركة (Layout)
- **`OperatorSidebar.tsx`**: شريط جانبي للتنقل، يحوي أيقونات للوصول السريع لـ Cockpit، Production، Materials. قابل للطي لزيادة مساحة الشاشة.
- **`OperatorHeader.tsx`**: شريط علوي يحوي:
  - اسم المستخدم (Operator Name).
  - الساعة الحية الدقيقة.
  - مؤشر الاتصال `ConnectionStatus`.
  - زر تمديد الشاشة الكاملة (Fullscreen).
