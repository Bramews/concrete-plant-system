# 22. الأمن والصلاحيات (Security, Auth, & Permissions)

هذا النظام يدير أصولاً بملايين الدولارات. أي اختراق أو ثغرة يعني خسائر فادحة للشركة (سرقة مواد، تخريب بيانات، إيقاف إنتاج).

## 1. التوثيق والجلسات (Authentication & Sessions)
- **مكتبة Auth:** يعتمد على NextAuth.js (أو نظام Custom JWT Auth) آمن.
- **الـ Session Token:** يُخزن في HttpOnly Secure Cookies لكي لا يستطيع أي سكريبت خبيث (XSS) قراءته وسرقته من المتصفح.
- **انقضاء الجلسة (Session Timeout):** جلسة المشغل لا تنتهي بسرعة (مثلاً مدتها 12 ساعة) لكي لا يتم تسجيل خروجه فجأة أثناء خلطة خرسانية مما يسبب شللاً في العمل. أما حساب المحاسب فقد تنتهي جلسته خلال 30 دقيقة من الخمول لأسباب أمنية.

## 2. التفويض والصلاحيات (Authorization & Roles)
- الصلاحيات ليست مجرد إخفاء الأزرار في ה-Frontend (فالمخترق יכול التعديل في الـ HTML وإظهار الزر).
- **ה-Middleware و ה-Server Actions:** الحماية الحقيقية تتم في السيرفر. كل دالة `Action` تحتوي في أول سطر لها:
  ```typescript
  const user = await verifyAuth();
  if (user.role !== 'OPERATOR' && user.role !== 'SYSTEM_OWNER') throw new Error("Unauthorized");
  ```
- **عزل الشركات (Tenant Isolation):**
  - لا توجد دالة Query واحدة في قاعدة البيانات لا تحتوي على `where: { companyId: user.companyId }`.
  - إذا نسي المبرمج كتابتها، فإنه قد يعرض طلبات مبيعات لشركة منافسة!

## 3. حماية العمليات (Operation Security)
- **تجميد البيانات (Immutability):** 
  - ה-MixDesign إذا اعتُمد يتجمد.
  - الـ DeliveryTicket إذا صُدرت لا تحذف (تُطبع كمرتجع إذا لزم الأمر لكن السجل الأساسي يبقى).
  - هذا يمنع المحاسب أو المشغل المتلاعب من محو آثار جريمته.
- **סجل التدقيق (Audit Log):** 
  - כל حركة مهمة تُسجل: (أحمد غيّر سعر الإسمنت من 100 إلى 90، الساعة 3 عصراً، من IP كذا).
  - جدول `AuditLog` مغلق لا يقبل الـ UPDATE أو DELETE أبداً.

## 4. حماية واجهة ה-PLC (Hardware Security)
- اتصال ה-Modbus TCP/IP هو اتصال غير مشفر (Unencrypted Plain Text).
- **الخطر:** إذا دخل شخص من شبكة المصنع وأرسل بـ Python أمر "فتح بوابة الإسمنت للآخر"، سوف يغرق المصنع.
- **ה-Architecture الآمنة:** 
  - يجب أن يكون الـ PLC والسيرفر المحلي (Edge Server) على شبكة LAN فيزيائية منفصلة تماماً (Air-gapped) عن شبكة الإنترنت العادية الخاصة بالموظفين.
  - السيرفر المحلي وحده يمتلك واجهة للإنترنت (VPN أو Encrypted Tunnel) للتحدث مع السحابة المركزية للمزامنة، ويمنع أي اتصال خارجي مباشر بالـ PLC.

## 5. الحماية ضد الـ Brute Force والـ DDoS
- يتم وضع Rate Limiting على صفحة الـ Login لمنع تخمين كلمات السر.
- الـ APIs العامة (مثل Webhooks) يتم فحص توقيعها (Signature Verification) بدقة شديدة.
